# MagTech CyberLab

Сайт киберполигона МГТУ им. Г. И. Носова на HTML, CSS и JavaScript.

## Локальный просмотр

Из корня репозитория запустите статический сервер (нужен Python 3):

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Для остановки сервера нажмите `Ctrl+C`.
